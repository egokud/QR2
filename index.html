Вставь URL веб-приложения из Google Apps Script. Как получить URL?

Как получить URL скрипта

1. Открой свою Google таблицу
2. Расширения → Apps Script
3. Вставь код скрипта (есть в README на GitHub)
4. Развернуть → Новое развертывание
5. Тип: Веб-приложение, доступ: Все
6. Нажми Развернуть и скопируй URL
