Политика конфиденциальности

Последнее обновление: 15 сентября 2026 г.

Мы серьёзно относимся к конфиденциальности ваших данных. Piksta не продаёт, не передаёт и не анализирует содержимое ваших заказов и посылок. Ваши торговые данные принадлежат только вам.

1. Кто мы

Оператором персональных данных является индивидуальный предприниматель Кудинов Егор Сергеевич, предоставляющий сервис Piksta по адресу piksta.online. Контакт: egokud@gmail.com.

2. Какие данные мы собираем

Данные регистрации: имя, адрес электронной почты, зашифрованный пароль.

Рабочие данные: трек-номера посылок, названия складов и получателей, которые вы вносите в Сервис. Эти данные хранятся исключительно для обеспечения работы Сервиса и доступны только вам.

Технические данные: информация об устройстве и браузере, IP-адрес, время последнего входа — для обеспечения безопасности аккаунта.

Платёжные данные: Piksta не хранит данные банковских карт. Оплата обрабатывается платёжными провайдерами.

3. Как мы используем данные

  • для предоставления функционала Сервиса;
  • для авторизации и защиты вашего аккаунта;
  • для отправки технических уведомлений (например, об окончании тестового периода);
  • для поддержки пользователей при обращении к нам.

Мы не используем ваши рабочие данные (треки, склады, получатели) в маркетинговых целях или для анализа вашей коммерческой деятельности.

4. Хранение и защита данных

Данные хранятся в защищённой облачной инфраструктуре Google Firebase с шифрованием при передаче (TLS) и хранении. Доступ к данным имеют только авторизованные сотрудники Сервиса в случаях, необходимых для поддержки.

Рабочие данные каждого пользователя изолированы: ни один пользователь не имеет доступа к данным другого.

5. Передача данных третьим лицам

Мы не продаём и не передаём ваши данные третьим лицам, за исключением:

  • платёжных провайдеров — для обработки транзакций;
  • облачной инфраструктуры (Google Firebase) — для хранения данных;
  • случаев, предусмотренных действующим законодательством.

6. Chrome-расширение Piksta

Chrome-расширение Piksta работает локально в вашем браузере. Оно считывает данные о заказах со страниц торговых площадок (Pinduoduo и др.) в рамках вашей авторизованной сессии. Расширение не передаёт данные вашей авторизации (логины, пароли, токены) на серверы Piksta. На серверы передаются только трек-номера и связанные с ними данные, которые вы явно выбираете для импорта.

7. Ваши права

Вы вправе:

  • получить копию своих данных — по запросу на email;
  • исправить неточные данные в личном кабинете;
  • удалить свой аккаунт и все связанные данные — через настройки или по запросу;
  • отозвать согласие на обработку данных, удалив аккаунт.

8. Файлы cookie

Сервис использует технические cookie, необходимые для авторизации и работы сессий. Аналитические и маркетинговые cookie используются только с вашего согласия.

9. Изменения политики

При существенных изменениях мы уведомим вас по email не менее чем за 7 дней. Актуальная версия всегда доступна по адресу piksta.online/privacy.
